! Description: Softens legacy Japanese web typography by replacing MS PGothic / MS UI Gothic on text content while minimizing icon and UI breakage.
! Description-ja: MS Pゴシック / MS UI Gothic 系の古い本文フォント指定を、Windows向けの読みやすい日本語フォントスタックへ置換します。
! Target: uBlock Origin
! License: CC0-1.0
!
! Design:
! - Fast path: inline legacy-font declarations.
! - Low-cost global fallback: body/main/article only.
! - Japanese-language fallback: common text elements only.
! - Avoids generic span/i/svg/icon rewriting.
!
! Replacement stack:
! system-ui, "Yu Gothic UI", "Yu Gothic", Meiryo, "Noto Sans CJK JP", sans-serif
!
! ---------------------------------------------------------------------------
! Fast path: explicit inline legacy Japanese font declarations
! ---------------------------------------------------------------------------

##:is(body,main,article,section,p,li,dd,dt,td,th,a,strong,em,label,button,input,textarea,select)[style*="MS PGothic" i]:style(font-family: system-ui, "Yu Gothic UI", "Yu Gothic", Meiryo, "Noto Sans CJK JP", sans-serif !important;)
##:is(body,main,article,section,p,li,dd,dt,td,th,a,strong,em,label,button,input,textarea,select)[style*="MS P Gothic" i]:style(font-family: system-ui, "Yu Gothic UI", "Yu Gothic", Meiryo, "Noto Sans CJK JP", sans-serif !important;)
##:is(body,main,article,section,p,li,dd,dt,td,th,a,strong,em,label,button,input,textarea,select)[style*="ＭＳ Ｐゴシック" i]:style(font-family: system-ui, "Yu Gothic UI", "Yu Gothic", Meiryo, "Noto Sans CJK JP", sans-serif !important;)
##:is(body,main,article,section,p,li,dd,dt,td,th,a,strong,em,label,button,input,textarea,select)[style*="MS UI Gothic" i]:style(font-family: system-ui, "Yu Gothic UI", "Yu Gothic", Meiryo, "Noto Sans CJK JP", sans-serif !important;)
##:is(body,main,article,section,p,li,dd,dt,td,th,a,strong,em,label,button,input,textarea,select)[style*="ＭＳ ＵＩゴシック" i]:style(font-family: system-ui, "Yu Gothic UI", "Yu Gothic", Meiryo, "Noto Sans CJK JP", sans-serif !important;)

! ---------------------------------------------------------------------------
! Global computed-style fallback
! Restrict to high-level text containers to keep procedural cost low.
! ---------------------------------------------------------------------------

##:is(body,main,article):matches-css(font-family: /(?:MS\s*P\s*Gothic|ＭＳ\s*Ｐゴシック|MS\s*UI\s*Gothic|ＭＳ\s*ＵＩゴシック)/i):style(font-family: system-ui, "Yu Gothic UI", "Yu Gothic", Meiryo, "Noto Sans CJK JP", sans-serif !important;)

! ---------------------------------------------------------------------------
! Japanese-language computed-style fallback
! Expands detection only when the document is explicitly Japanese.
! ---------------------------------------------------------------------------

##html:lang(ja) :is(section,p,li,dd,dt,td,th,a,strong,em,label,button,input,textarea,select):matches-css(font-family: /(?:MS\s*P\s*Gothic|ＭＳ\s*Ｐゴシック|MS\s*UI\s*Gothic|ＭＳ\s*ＵＩゴシック)/i):style(font-family: system-ui, "Yu Gothic UI", "Yu Gothic", Meiryo, "Noto Sans CJK JP", sans-serif !important;)

! ---------------------------------------------------------------------------
! Intentional exclusions
! ---------------------------------------------------------------------------

! MS Gothic / ＭＳ ゴシック is not globally replaced because it can be
! intentionally used for fixed-width tables, ASCII layouts, or code-like text.
! MS Mincho / MS PMincho are also left unchanged to preserve serif typography.
!
! Icon/symbol elements are intentionally not targeted by broad span/i/svg rules.
